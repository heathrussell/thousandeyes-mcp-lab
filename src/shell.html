// 00 · What you’ll build today

What you’ll walk out with

This lab is for engineers and developers who build with AI. By the end of it you will have an agent that reads live ThousandEyes data, follows a triage runbook you wrote, and runs on a schedule without you in the loop.

House rules

  • Any order. Checkpoints are independent. Do Labs 1, 3 and 5 at minimum.
  • Three free tries per checkpoint, then −10 points for each wrong answer.
  • Hints cost 25 points each. They point you to the right section without giving the answer away.
  • It’s a shared org. Prefix everything you create with your initials, and delete it in Lab 6.
  • Read what the tool is about to do. Your client asks before every write. That is the production pattern too.

    // 01 · Core · 5 min · 100 pts

    Choose your poison: connect your AI client

    ThousandEyes publishes one hosted MCP server at https://api.thousandeyes.com/mcp. Any client that speaks MCP over HTTP can use it. Pick the one you build in, follow its panel, run the verify prompt, and you’re ready for the labs.

    Tool directory

    54 tools, grouped the way you’ll use them. READ tools only read. WRITE tools create, change or delete things in your org. UNITS tools execute live tests and consume ThousandEyes units. Claude groups the read-only and write/delete tools separately when it asks for permission, so you can always allow reads and keep writes on ask.
